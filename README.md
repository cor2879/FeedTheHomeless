# Feed The Homeless

A browser-based arcade lane-crossing game created by **Andrew Cole**.

Help Ray deliver hot meals safely across increasingly dangerous city streets.

## Features

- 100 levels across 10 worlds
- World and level progression with star ratings
- Persistent browser save data
- Multiple vehicle and hazard types
- Powerups, score bonuses, weather, and dog-chase events
- Desktop and mobile controls
- Touch-friendly pause and powerup controls
- Local leaderboard and settings

## Controls

### Desktop
- Arrow Keys / WASD — Move
- Space — Use held powerup
- P / Escape — Pause

### Mobile
- Swipe — Move
- Tap buttons — Navigate menus
- Tap **USE** — Activate a held powerup
- Tap **PAUSE** — Pause
